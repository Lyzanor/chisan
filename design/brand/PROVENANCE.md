# Chisan v0.3 asset provenance

Source reference: `design/references/v0.3/chisan-wordmark-first-board.png`.

Map-marker reference:
`design/references/v0.3/chisan-marker-join-board.png`. The user selected The
Join directly from this board. The runtime vector is copied from the matching
approved source at `design/references/v0.2/chisan-mark.svg`; it is not redrawn
or approximated in CSS.

The production raster assets were created with the built-in OpenAI image
generation tool from the approved option 1 board. They are intentionally kept
as image assets rather than approximated with live type or code geometry.

## Wordmark prompt

> Isolate and faithfully recreate only the lowercase `chisan` wordmark from
> the selected board as a crisp, high-resolution transparent PNG in solid ink
> `#1D201B`. Preserve the custom lowercase proportions, open `c`, wide geometric
> rhythm, single-storey `a` and optical spacing. Include no background, tagline,
> symbol, border, shadow, gradient, labels or extra text.

## Compact glyph prompt

> Isolate the compact `c` from the selected board as a crisp, high-resolution
> transparent PNG in solid ink `#1D201B`. Preserve its open circular form,
> diagonal-cut terminals, weight, aperture and 16 px legibility. Optically
> centre it with clear space. Include no background, wordmark, tagline,
> container, border, shadow, gradient, labels or extra text.
