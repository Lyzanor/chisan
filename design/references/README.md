# Chisan design references

Reference captures document why a direction was chosen. They are not runtime
assets and must not be copied as page templates.

- `inspiration-sanko-mobilefirst.png` — viewport capture of
  <https://sankoudesign.com/category/mobilefirst/>, 2026-08-30. Useful for

- `inspiration-alltrails-explore.png` — viewport capture of
  <https://www.alltrails.com/explore>, 2026-08-30. Useful for small circular

Use these references to judge principles and relationships. Chisan keeps its
own identity, catalog structure, copy and interaction semantics.
