# World Cheese add targets

Listado operativo para futuras sesiones. Incluye los 77 candidatos `Añadir` y los 15 `Añadir normalizado` de `docs/WORLD_CHEESE_CANDIDATES.md`, usando un nombre de búsqueda limpio para los casos de Gran Canaria con `& CABILDO DE GRAN CANARIA`.

Para cada productor, buscar fuente primaria o Google Maps antes de crear fila CSV. Usar `Lácteos y quesos` como categoría salvo que la revisión demuestre otro encaje.
