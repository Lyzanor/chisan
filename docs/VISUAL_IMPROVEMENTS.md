# Visual Notes

## Current Direction
- The app is map-first: province selector, category chips, map, and producer viewer.
- Avoid reintroducing a complex search surface unless there is a concrete data workflow need.
- Keep detail pages plain: canonical URL, producer metadata, external links, and the CSV field table.

## UI Guardrails
- Prefer dense, scannable controls over marketing-style sections.
- Keep the map and producer list visible without extra navigation.
- Use one shared placeholder image at `/productores/generica.webp`.
- Per-producer images follow the editorial guidelines in `docs/CSV_CONTRACT.md` → *Producer image guidelines* (1600×1200 WebP, cream `#F3F0E8` background, logo-first avatar style).
