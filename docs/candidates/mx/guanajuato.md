# Guanajuato — candidates

- Target CSV: `data/csv/mx/centro-occidente/guanajuato.csv`
- Source: Consejo Regulador del Tequila, *Marcas de tequila de envasado de origen
  certificadas*, XLSX updated 3 August 2026, linked from
  https://www.crt.org.mx/en/brands-and-associates/
- Searched: 16 August 2026
- Batch scope: every company the file registers in this state. The tequila
  appellation covers this state only in named municipalities, so confirming the
  address is inside it is part of resolving each candidate.

The CRT certifies these companies to bottle tequila inside the appellation. That
supports identity and the appellation, not current activity or online sales.
The file's address is fiscal and its phone is generated, not a contact — take
`municipio` and `telefono` from the producer.

`categoria` for all of them is `Destilados y licores`.
