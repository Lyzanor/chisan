# Candidatos — Venezia

Revisión cerrada el 2026-08-12 para el lote abierto el 2026-08-08. Se incorporaron al CSV Latifondo 63, Andalenta, Pasta di Caorle — Agricola F.lli Borin, La Baratta, Basso Anna y Agri-Birrificio B2O. Las filas siguientes quedan retenidas: el certificado ecológico o el registro empresarial acredita una actividad agraria, pero no permite publicar todavía una marca alimentaria concreta, una oferta propia actual o la unidad productiva correcta sin inferencias.
