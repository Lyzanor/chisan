# Candidatos — Overijssel

Segunda revisión individual del 2026-08-09. Quedan 16 operadores certificados retenidos por no mostrar una oferta alimentaria propia, actual y públicamente atribuible suficiente. B.J.A. van den Berg se descartó porque la explotación lechera terminó y el erf fue transformado y vendido como vivienda.
