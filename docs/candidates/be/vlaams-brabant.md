# Candidatos — vlaams-brabant

Segunda revisión de 2026-08-09. Se confirmaron quince productores, uno de ellos reubicado en Antwerpen; se descartó una explotación exclusivamente floral. Se aplicaron Pajottegem y Merchtem como municipios actuales.
