# Bélgica — revisión integral de candidatos

Revisión cerrada el 2026-08-09 sobre los 220 candidatos de las once áreas belgas. Se inspeccionó cada ficha de descubrimiento y se aplicaron los límites de la fuente correspondiente: una tienda de granja de VLAM no prueba por sí sola producción propia, y una ficha de Apaq-W no demuestra actividad actual si no existe una presencia productora independiente.

Se publicaron 21 productores para los que fue posible confirmar identidad, producción o elaboración propia, municipio oficial, ubicación y actividad actual; sus candidaturas se retiraron de la cola. Los 199 casos restantes están revisados y retenidos, no rechazados: necesitan una fuente actual del productor o una prueba inequívoca de que la dirección corresponde a la unidad productiva. `Espace test agricole` permanece además porque es una infraestructura para proyectos cambiantes, no una única unidad productora publicable.

La fecha de corte de esta revisión es 2026-08-09. Cualquier candidato añadido después pertenece al siguiente lote.
