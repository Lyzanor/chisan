# Candidatos — Thüringen

Revisión individual de la tanda TRACES de 17 operadores (corte 2026-08-09). Se publicaron cinco productores y se descartaron dos entidades: una sociedad de gestión/energía sin oferta alimentaria y una sociedad disuelta. Los diez casos siguientes permanecen retenidos por falta de una oferta alimentaria pública suficientemente atribuible o por una contradicción aún no resuelta.

| Candidato retenido | Municipio declarado | Motivo de retención |
|---|---|---|
| Agrar GmbH Weisheit | Barchfeld-Immelborn | La sociedad produce y comercia productos agrarios, pero no se encontró un alimento concreto ni un canal público atribuible. |
| Agrarbetrieb "Freier Bauer" GmbH | Ilmtal-Weinstraße | Sociedad agrícola activa, sin producto alimentario concreto ni oferta pública verificable. |
| Agrargesellschaft mbH Bernterode | Heilbad Heiligenstadt | Se confirma la explotación y sus servicios agrícolas, pero no una oferta alimentaria concreta. |
| Altenburger Naturrinder GbR | Göhren | La explotación ganadera está activa y registrada de nuevo en 2024, pero no apareció una oferta pública de carne atribuible. |
| Andreas Kolchmeier | Bucha | Se confirma la identidad local, pero no alimento, marca o canal de comercialización fuera del certificado. |
| Anita Kleinteich | Gera | No se encontró evidencia pública suficiente fuera del certificado para establecer producto y oferta. |
| Arnold Mainzer, Florian Mainzer Mainzer GbR | Südeichsfeld | Se confirma la cría de ganado Salers, pero no una oferta alimentaria pública; un registro de criadores no prueba venta de carne. |
| Baumbach Jörg | Stadtilm | La identidad pública localizada no permite vincular el certificado con alimentos comercializados. |
| Bernhard Waldert | Harth-Pöllnitz | Hay una contradicción de identidad: un homónimo de Wetzdorf falleció en 2024, pero fuentes locales también muestran un agricultor homónimo activo; no se puede publicar ni descartar sin resolverla. |
| Biohof Martin GmbH | Großbartloff | La sociedad y el certificado existen, pero no se encontró producto alimentario o comercialización pública atribuible. |

Estos casos no se consideran falsos: continúan pendientes hasta que una fuente pública una identidad, alimento, unidad productiva y actividad actual.
