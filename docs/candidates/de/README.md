# Guía de candidatos — Alemania

Aplica la [guía común](../README.md) y las
[reglas y techos de fuentes de Alemania](../../../data/csv/de/AGENTS.md).

Este README es solo un punto de entrada estable. Cada Land documenta en su
propio fichero las fuentes, el corte y los candidatos pendientes de cada
barrido. No agregues aquí totales nacionales ni resultados de TRACES, del
directorio de queserías u otras pasadas: esos resúmenes quedan obsoletos al
primer cambio de un área.
