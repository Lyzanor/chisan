# Hamburg — candidatos pendientes

Revisado el 2026-08-08. Once de los trece candidatos de cerveza quedaron
integrados o rechazados. Permanecen dos casos cuyo lugar de producción actual no
se pudo situar con precisión:

| nombre | estado |
|---|---|
| Buddelship Brauerei | La [web oficial](https://www.buddelship.de/about/) confirma que abandonó la planta de Hamburgo en 2020 y se trasladó a una granja, pero no publica la ubicación productiva actual. El domicilio social de Hamburgo no basta para asignar el productor al área. |
| Kehrwieder Kreativbrauerei | La web oficial sigue activa pero bloquea la consulta automatizada; fuentes recientes se contradicen sobre si la producción continúa en Sinstorf o fue trasladada a Rügen. Falta una fuente propia accesible que sitúe la elaboración actual. |
