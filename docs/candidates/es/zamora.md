# Zamora — candidate holds

- Target CSV: `data/csv/es/castilla-y-leon/zamora.csv`
- Editorial review: 2026-09-21; 64 unresolved candidate entries remain.
- The pass worked the Castilla y León artisan register, the Tierra de Sabor producer directory, web searches for the register holders and the queue's own first-party links against the published catalog. A register or directory check is not proof of current activity.
- Discovery statements in the tables retain their original source limits. The remaining-work field records what still prevents admission; inaccessible or insufficient sources do not establish an exclusion.
- Resolved admissions, confirmed duplicates and closed exclusions have left this queue. Approved facts and closed decisions belong to the canonical CSVs and evidence ledgers.
- Editorial and source rules: `docs/EDITORIAL.md`, `docs/EVIDENCE_CONTRACT.md` and `data/csv/es/AGENTS.md`.
- **Tierra de Sabor**, the Junta's regional quality brand, is a producer directory for all nine provinces: `tierradesabor.es/producers-sitemap.xml` lists 664 fichas at `/productores/<slug>-<id>/`, and each carries the name, email, website and an address ending in the province in parentheses. Its REST API is closed. The server throttles bulk reads — about 260 quick requests returned full pages and then empty ones, and later the host refused connections outright — so read it sequentially and slowly, or look up single fichas. It resolved Hornopan Hermanos Coomonte, and its email column showed that El Trillo is the published Agroalimentaria de la Guareña (`info@legumbrestrillo.com`).
- In the artisan register the Zamora code is `prov=ZA`; `refine.prov=ZA` returns 64 rows for 45 holders with their `domicilio_industrial`. Matching those addresses and the producers' domains against the catalog closed three entries: Cardiza is the published Cárnicas Díaz de Zamora (`carnicasdiaz.com` frames the published `buenosdiaz.es`), Queso artesano Hircus is the published Hircus / Caprino del Esla, and El Trillo is above.
- Municipality traps found here: **Tapioles is a municipality**, not a locality of Villafáfila as this queue had it; postcode 49335 is shared by Ferreras de Abajo and Ferreras de Arriba, so the register decides between them; and Rejadorada, a D.O. Toro winery, has made its wine since 2003 at San Román de Hornija, which is in Valladolid.
