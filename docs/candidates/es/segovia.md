# Segovia — candidate holds

- Target CSV: `data/csv/es/castilla-y-leon/segovia.csv`
- Editorial review: 2026-09-20; 35 unresolved candidate entries remain.
- The pass worked the Alimentos de Segovia member directory and the Castilla y León artisan register against the published catalog. A directory or registry check is not proof of current activity.
- Discovery statements in the tables retain their original source limits. The remaining-work field records what still prevents admission; inaccessible or insufficient sources do not establish an exclusion.
- Resolved admissions, confirmed duplicates and closed exclusions have left this queue. Approved facts and closed decisions belong to the canonical CSVs and evidence ledgers.
- Editorial and source rules: `docs/EDITORIAL.md`, `docs/EVIDENCE_CONTRACT.md` and `data/csv/es/AGENTS.md`.
- Alimentos de Segovia, the Diputación's provincial quality club, is the richest source for this area. Its REST API is closed by Kadence Security, but `sitemap_index.xml` exposes `directorios-sitemap{1,2}.xml`, which list all 271 member pages at `/directorios/<slug>/`. Each page carries the trade name, the productive address, phone, email, website, a descriptive summary and a membership label. That label is a filing decision, not an editorial one: it files some producers with an own obrador under *Comercios asociados*. The producers page itself is client-rendered — the member list reaches the HTML only as a search autocomplete array of bare names.
- Club membership does not place a row in this province: Bodegas Maeste is a Segovia club member whose productive address is in Honrubia de la Cuesta, Burgos.
- In the Castilla y León artisan register the Segovia province code is `prov=SE`, not `SG`, although its entry codes read `EAA-SG/xxxx`. Query it with `refine.prov=SE`; `q=prov:SG` returns nothing and looks like an empty province.
- A register `domicilio_industrial` that differs from a published row's address does **not** prove a different productive unit. SANCHONAR, S.L. is registered at Polígono Dehesa Boyal 7, Sanchonuño, while the published Ecosancho row carries C/ Molino 18 — the club directory shows they are the same business at its elaboration premises and its postal address. A differing address opens the question; only a matching street *and* number closes it.
- CartoCiudad silently drops to street-level neighbours when the query carries the province name. `Calle Reina 12, San Ildefonso` returns the exact portal; `Calle La Reina 12, Real Sitio de San Ildefonso, Segovia` returns 10, 11, 13 and 14 and no 12. Query street, number and municipality only, then check `portalNumber` before accepting the point.
