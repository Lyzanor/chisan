# Santa Coloma gallery rights follow-up — 2026-09-25

The eight real-producer gallery packages introduced by `0a3f7168e` contained
32 photographs but no recorded reuse authorization. Review of their official
sources did not establish public permission for Chisan to republish them.
The local correction removes these packages (which contained only gallery
items) and their 32 public assets. Catalog identities and base facts remain.
This is an editorial hold, not a legal finding that every possible use is unlawful.
Matching temporary discovery copies for these eight producers were discarded;
the source manifest remains as a reference, not a photo library.

The declared fictional Chisan demo `(es, 12439)` is outside this source-photo
audit. Existing primary identity images/logos are also outside this gallery
batch. A local commit does not withdraw files from an existing deployment or
erase earlier Git history.

source context again. The old batch mislabeled Catalan alt text as Spanish;
filenames and generic website credit are not evidence of authorship or rights.
