# Guide content

Spanish editorial articles live in `es/<slug>.md`. Markdown is the canonical text
source; YAML front matter holds the article metadata. There is no JSON copy.
Producer names, coordinates and routes resolve from stable CSV identities.

Read [Editorial guides](../../docs/GUIDES.md) for syntax, publication rules and
the update workflow. Edit the document directly or request the revision in Codex.
Use `status: draft` for unpublished work and run `pnpm check:guides` after edits.
There is no administration editor yet. Reviewed changes publish through Git.
